# Demo Video Recording Guide (Phase 1)

For Phase 1 submission, record a quick 1-2 minute video showing:
1. The GitHub repository: https://github.com/hharshithkumar91-crypto/mdds-location-intelligence-platform
2. The 3NF Prisma schema: prisma/schema.prisma
3. Terminal execution: Running 'python scripts/verify_pipeline.py' showing 100% integrity verification.

## Suggested Tools:
- Windows Built-in Screen Recorder (Press Win + Alt + R)
- Loom (https://www.loom.com)
- OBS Studio

Once recorded, drop your video file (.mp4, .mkv) or Loom link directly into this folder on Google Drive.
