6. API Development Specifications

The API gateway provides high-throughput, low-latency administrative hierarchy lookups and typeahead search.

Standard Response Envelope (Section 6.3)

{
  "success": true,
  "count": 25,
  "data": [ ... ],
  "meta": {
    "requestId": "req_ad7b5b3fb8bd",
    "responseTime": 12,
    "rateLimit": {
      "remaining": 4850,
      "limit": 5000,
      "reset": "2026-09-12T00:00:00.000Z"
    }
  }
}

7. Frontend Dashboard Requirements

Built with React 18+, Vite, Tailwind CSS, and Recharts. Global state managed by Zustand, server caching via TanStack React Query.

  • Initial load time: < 1.5 seconds.
  • Chart render time: < 500ms.
  • Table pagination & filtering: < 300ms.

8. Admin Panel Specifications

Includes user approval workflow, state-level regional access control, village data browser, and live API telemetry logs with status filters and CSV export.

9. B2B User Portal Specifications

Features corporate self-registration (disposable email filtering), usage summary cards, cryptographic API key creation (displaying secrets once), and built-in interactive Swagger/OpenAPI documentation.

10. Authentication & Security Architecture

Multi-layered security with stateless JWT (24h), bcrypt secret hashing, rate limiting per tier, and mandatory HTTP security headers (nosniff, DENY, HSTS, CSP).
